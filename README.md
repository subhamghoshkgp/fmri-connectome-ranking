# Functional Connectome Classification and Ranking

Experiment code and Dataset-1 results for whole-brain and cortical-only functional connectivity classification.

The same 54 participants are evaluated at 83 and 129 regions and their cortical-only subsets of 68 and 114 regions. Code includes incidence-gated logistic learning, pairwise ranking, ranking with ridge refit, dense ridge ranking, LASSO, elastic net and RFE-SVM.

Core results contain 4,800 completed outer-fold metric rows and 32 primary summaries. The remaining source inputs, notebooks and fitted-model archives are currently being uploaded. See `UPLOAD_STATUS.md` for current completeness. No manuscript or conference material is included.
